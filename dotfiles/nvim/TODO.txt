knowledge nvim
substitue
:s substitutes only on the current line.
:s/foo/bar/g
Replaces foo with bar on the line where your cursor is.

:%s substitutes across the whole current buffer.
:%s/foo/bar/g
Replaces foo with bar on every line in the file.
:'<,'>s/foo/bar/g -> substitute only inside the visual selection lines

without g replaces first match in the line
with g replaces all matches per line
I case sensitive
e no errores if no matches
c confirm

:g/^o/s/foo/bar/g
  Meaning:
  - :g/^o/ -> only lines that start with o
  - s/foo/bar/g -> run this substitution on those lines

Opposite condition:
:v/^o/s/foo/bar/g
:v means “lines that do not match.”

Common :global conditions:
:g/foo/
Lines containing foo.

:v/foo/
Lines not containing foo.

:g/^foo/
Lines starting with foo.

:g/foo$/
Lines ending with foo.

:g/^\s*$/
Blank or whitespace-only lines.

:g/^\s*#/
Comment lines, for many shell/Python-style files.

:g/TODO\|FIXME/
Lines containing TODO or FIXME.

:g/\vfoo|bar|baz/
Same idea using very-magic regex, easier alternation syntax.

:g/\d/
Lines containing a digit.

:g/^\s\+/
Indented lines.

:g/^\S/
Non-indented lines.

:g/foo.*bar/
Lines where foo appears before bar.

:g/foo/.,+3s/a/b/g
For each line containing foo, apply substitution to that line and the next 3 lines.

:g/foo/+1s/a/b/g
For each line containing foo, apply substitution to the line after it.

:g/foo/normal @q
Run macro q on every line containing foo.

:v/keep/d
Delete every line that does not contain keep.

The main pattern is:
:g/{condition}/{command}
:v/{condition}/{command}

You pick a branch and a file → this is the “base file”
You pick another branch and a file → this is the “comparison file”
Both files are opened in Neovim (or your editor) as a diff, so you can see differences and edit either file on the fly
Temporary files are used so your working directory is safe
Perfect — we can do that with nvim -d (diff mode) or vimdiff and git show to extract the files.

gdiffedit() {
    local branch1 branch2 file1 file2 tmp1 tmp2 editor

    # Choose first branch
    echo "Select the first branch:"
    select branch1 in $(git branch --all | sed 's/^[* ]*//'); do
        [ -n "$branch1" ] && break
    done

    # Choose file from first branch
    echo "Select a file from $branch1:"
    select file1 in $(git ls-tree -r --name-only "$branch1"); do
        [ -n "$file1" ] && break
    done

    # Choose second branch
    echo "Select the second branch:"
    select branch2 in $(git branch --all | sed 's/^[* ]*//'); do
        [ -n "$branch2" ] && break
    done

    # Choose file from second branch
    echo "Select a file from $branch2:"
    select file2 in $(git ls-tree -r --name-only "$branch2"); do
        [ -n "$file2" ] && break
    done

    # Create temporary files
    tmp1=$(mktemp /tmp/gitfile1.XXXX)
    tmp2=$(mktemp /tmp/gitfile2.XXXX)

    # Extract files into temp files
    git show "$branch1:$file1" > "$tmp1"
    git show "$branch2:$file2" > "$tmp2"

    # Open in Neovim diff mode (editable)
    editor="${EDITOR:-nvim}"  # default to nvim if $EDITOR not set
    "$editor" -d "$tmp1" "$tmp2"

    # Ask if you want to copy changes back to working directory
    read -p "Do you want to save changes back to working tree? [y/N] " save_changes
    if [[ "$save_changes" =~ ^[Yy]$ ]]; then
        cp "$tmp1" "$file1"
        cp "$tmp2" "$file2"
        echo "Changes saved to $file1 and $file2"
    fi

    # Cleanup
    rm -f "$tmp1" "$tmp2"
}
Prompts for branch and file twice (base and comparison)

After editing, optionally copies changes back to the working directory

When calling the function myMethod if the user adds a valid directory as a parameter then all the files are created there, if invalid say invalid directory and if no parameter is given then the files should be created in the original path they where on the original branch
myMethod() {
  local output_dir=""
  local selections=()

  # -------------
  # Validate output directory
  # -------------
  if [ -n "$1" ]; then
    if [ ! -d "$1" ]; then
      echo "Invalid directory: $1"
      return 1
    fi
    output_dir="$(cd "$1" && pwd)"
  fi

  # -------------
  # Branch selection loop
  # -------------
  while true; do
    local branch
    branch=$(git branch --all --format='%(refname:short)' \
      | sed 's|^origin/||' \
      | sort -u \
      | fzf --prompt="Select branch (ESC to finish): ")

    [ -z "$branch" ] && break

    # -------------
    # File selection for branch
    # -------------
    local files
    files=$(git ls-tree -r --name-only "$branch" \
      | fzf --multi --prompt="Select files from $branch (ESC to skip): ")

    [ -z "$files" ] && continue

    while IFS= read -r file; do
      selections+=("$branch:$file")
    done <<< "$files"
  done

  # -------------
  # No selections → nothing to do
  # -------------
  if [ "${#selections[@]}" -eq 0 ]; then
    echo "No files selected. Nothing to do."
    return 0
  fi

  # -------------
  # Create files
  # -------------
  for entry in "${selections[@]}"; do
    local branch="${entry%%:*}"
    local file="${entry#*:}"

    local dir base name ext target_dir target_file

    dir="$(dirname "$file")"
    base="$(basename "$file")"
    name="${base%.*}"
    ext="${base##*.}"

    if [ "$name" = "$ext" ]; then
      ext=""
    else
      ext=".$ext"
    fi

    if [ -n "$output_dir" ]; then
      target_dir="$output_dir"
    else
      target_dir="$dir"
      mkdir -p "$target_dir"
    fi

    target_file="${target_dir}/${name}_${branch}_temp${ext}"

    if [ -e "$target_file" ]; then
      echo "Skipping existing file: $target_file"
      continue
    fi

    git show "$branch:$file" > "$target_file" || {
      echo "Failed to extract $file from $branch"
      continue
    }

    echo "Created: $target_file"
  done
}

In your flake.nix, define a variable:
nix

{
  description = "My NixOS config";

  inputs.nixpkgs.url = "github:NixOS/nixpkgs/nixos-26.05";

  outputs = { self, nixpkgs, ... }:
    let
      stateVersion = "26.05";
    in {
      nixosConfigurations.PC = nixpkgs.lib.nixosSystem {
        system = "x86_64-linux";
        modules = [
          ./configuration.nix
          { system.stateVersion = stateVersion; }
        ];
      };

      homeConfigurations.r = nixpkgs.lib.homeManagerConfiguration {
        pkgs = nixpkgs.legacyPackages.x86_64-linux;
        modules = [
          ./home_configuration.nix
          { home.stateVersion = stateVersion; }
        ];
      };
    };
}

Here, stateVersion is defined once and injected into both system and home configs.
🛠️ Example with plain configuration.nix

If you’re not using flakes, you can still use a let binding:
nix

{ config, pkgs, ... }:

let
  stateVersion = "26.05";
in
{
  system.stateVersion = stateVersion;

  imports = [
    ./home_configuration.nix
  ];
}

Then in home_configuration.nix, you can reference it if you pass stateVersion via specialArgs:
nix

{ config, pkgs, stateVersion, ... }:

{
  home.stateVersion = stateVersion;
}
